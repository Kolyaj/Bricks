# Deprecated-модули не тестируются

План тестирования `dresscode-bricks` (2026-09) распространяется на все живые модули. Решение: deprecated-модули (`Bricks.Widget`, `Bricks.AbstractWidget`, `Bricks.StringWidget`, `Bricks.XHR`, `Bricks.Request` — ~760 строк) тестами не обеспечиваются.

- **Status**: accepted (2026-09)

## Considered options

- **Полное покрытие** как у живых модулей — **отклонено**: свиты для мёртвого кода дают ложный сигнал, будто модуль жив и развивается.
- **Контрактные/смок-тесты** публичного API deprecated-модулей — **отклонено** как отправная точка: даже контрактный тест это старт сопровождения модуля в конечном состоянии.
- **Не тестируются до первого фикса** — **принято**: если в deprecated-модуле понадобится фикс (в т.ч. known-bugs из `todo.md`), тест пишется вместе с фиксом.

## Consequences

Обещание ADR 0001 (обратная совместимость deprecated-модулей) остаётся *непроверенным*: гарантия — доверие, а не тесты. Регрессия в deprecated-модуле, если обнаружится, чинится вместе с тестом, не превращая модуль в «развиваемый».
