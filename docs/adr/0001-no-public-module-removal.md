# Публичные модули не удаляются

`dresscode-bricks` — опубликованная фундаментальная класс-библиотека DressCodeJS с живыми потребителями. Решение: публичный модуль никогда не удаляется из библиотеки, каким устаревшим он ни казался.

- **Status**: accepted (2026-09)

## Considered options

- **Удалить** deprecated-модули (~700 строк legacy UI-слоя `Widget`/`AbstractWidget`/`StringWidget`, network `XHR`/`Request`), чтобы облегчить код — **отклонено**.
- **Оставить** модуль на месте с `@deprecated` в JSDoc — **принято**.

## Consequences

Причина, по которой удаление отклонено, load-bearing: потребитель, обновивший библиотеку ради нового модуля, не должен ничего потерять — всё, что он использует, должно продолжать работать.

Вес удержания нулевой: проект собирается сборщиком DressCode (dresscodejs), который кладёт в бандл только фактически используемый код. Неиспользуемый deprecated-модуль в бандл не попадает и потребителю ничего не стоит.

`@deprecated` — **конечное состояние** модуля: он остаётся в пакете, не развивается и не рекомендуется в новом коде. Способов выразить устаревание, кроме этой метки, у нас нет.

Архитектурные review не должны предлагать удаление публичных модулей. Ненарушающие доработки deprecated-модулей (фиксы багов, замена опасных конструкций в place) допустимы.
